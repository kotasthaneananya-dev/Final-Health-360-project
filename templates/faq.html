Frequently Asked Questions

What is the primary goal of this analytics dashboard?

The platform explores patterns in patient healthcare data, mapping risk factors like blood pressure, exercise frequency, and BMI to chronic health risks.

How are the visualizations rendered?

The visualizations are embedded directly from Tableau Public via responsive HTML API frames so users can interact with filters in real time.

Can I run this project locally?

Yes! Clone the GitHub repository, install Flask via terminal using `pip install -r requirements.txt`, and run `python app.py`.
