# Smart Healthcare Analytics: Patient Risk & Lifestyle Insights

A full-stack Flask web application integrated with interactive Tableau Public dashboards and data stories analyzing comprehensive patient healthcare risks, lifestyle indicators, blood pressure metrics, and disease correlations.

## Features

- **Flask Framework:** Dynamic routing across Home, About, Dashboard, Story, and FAQ pages.
- **Tableau Public Integration:** Embedded responsive healthcare data visualizations and analytical story flows.
- **Lifestyle & Risk Insights:** Age group breakdowns, BMI vs heart disease patterns, exercise distribution analysis, and blood pressure correlations.

## Running Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
